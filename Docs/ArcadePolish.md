# Orbit Breaker 개선 사항

`Assets/01.Scenes/SampleScene.unity`를 열고 Play를 누르면 바로 시작합니다.
기존 ShootingPack 픽셀 아트와 Cartoon FX 이펙트를 재사용했습니다. 추가 에셋이나 패키지 설치는 없습니다.

## 조작

| 키 | 기능 |
| --- | --- |
| WASD / 방향키 | 이동 |
| Shift 누르기 | 정밀 이동 (기본 속도의 45%) |
| Space 누르기 | 연속 발사 |
| 1 | 자동 발사 켜기 / 끄기 (시작 시 켜짐) |
| B | 확장형 폭탄, 쿨다운 10초 |
| P / Esc | 일시정지 / 계속 |
| R | 일시정지 또는 결과 화면에서 재시작 |
| M | 효과음 켜기 / 끄기 |
| Q / E | 속도 미세 조정 (1~8) |

## 플레이와 외관

- 우주 별 배경, 중앙 비행 구역, 청록색 HUD와 조작 안내.
- 체력, 폭탄 재충전, 점수, 최고 기록, 구역, 생존 시간 표시.
- 3초 안에 이어서 적을 처치하면 체인이 이어집니다. 5체인마다 배율이 오르며 최대 5배입니다.
- 25초마다 구역이 바뀌고 생성 간격이 짧아집니다. 최대 압박 배율은 2.2입니다.
- 피격 후 1.2초 무적과 깜빡임, 작은 화면 흔들림, 발사·피격·폭탄·획득 효과음.
- 폭탄은 3초 동안 반경 0.55에서 2.6으로 확장합니다. 원 테두리가 실제 판정 범위이며 내부는 반투명입니다.
- 이동 범위를 벗어나지 않도록 기본 동작을 제한했습니다. 기존 좌우 래핑은 PlayerMove의 Wrap Horizontally로 다시 켤 수 있습니다.
- 사망 시 결과 화면과 재시작을 제공합니다. 앱에서 포커스가 벗어나면 자동 일시정지합니다.

## 설정 위치

- 씬의 **Orbit Breaker - Game Session**: 구역 지속 시간과 체인 유지 시간.
- **Player.prefab**: 속도, 이동 범위, 연사 간격, 피격 무적 시간.
- **Bomb.prefab**: 수명, 시작 반경, 최대 반경.
- **Spanwer.prefab**: 초기 생성 간격, 좌우 생성 편차, 기존 50/30/20 적 구성.
- GameSession이 HUD, 배경, 효과음 컴포넌트를 생성하므로 별도 수동 연결이 필요하지 않습니다.
- 효과음은 짧은 합성 오디오로 생성됩니다. 최고 기록과 음소거 상태는 PlayerPrefs에 저장됩니다.
- 가로 화면과 9:19 세로 화면을 지원합니다. 좁은 화면에서는 상단 점수/구역과 체력/폭탄을 나누고,
  하단 조작 안내를 두 줄로 배치합니다. 실행 중 화면 크기가 바뀌면 자동으로 다시 배치합니다.

## 검증

Rider 전체 C# 빌드와 별도 Unity 프로젝트 복사본의 런타임 검증을 사용합니다.
`ArcadeSmoke.cs`는 검증 복사본의 `Assets/Editor`에 넣어 batchmode로 실행하는 스크립트이며, 원본 프로젝트에서는 컴파일되지 않습니다.

검사 항목: 씬/HUD/프리팹 연결, 연속 피격 무적, 회복 상한, 공격 속도 상한,
화면 밖 이동 제한, 중복 처치 점수, 아군 탄환 충돌, 폭탄 범위와 수명,
일시정지와 재개, 사망 상태, 재시작 초기화 및 세션 중복 방지.

검증 중 화면은 `Artifacts/flight.png`, `paused.png`, `results.png`로 렌더링됩니다.
검증 프로젝트와 로그는 원본의 Git 제외 경로인 `Temp/PolishValidation`에 있습니다.

2026-09-09 검증 결과: Unity 6000.3.22f1에서 런타임 검사 20개 통과, 전체 C# 빌드 통과.
비행 중·일시정지·결과 화면을 렌더링하여 확인했습니다. 원본 Unity 창 조작은 Escape 입력 이후 중단했습니다.
검증 복사본 초기화 로그에는 Unity Editor Search 인덱스 예외 및 라이선스 갱신 경고가 있었지만,
게임 스크립트 컴파일과 런타임 검사는 완료되었습니다. 실제 키보드/마우스를 통한 수동 플레이와 소리 청취는 검증 범위에 포함되지 않습니다.
